# Data Dictionary & Schema Specification

## 1. Raw Dataset: METR-LA (HDF5)

| Field Name | Type | Unit | Description | Missing Value Convention |
| :--- | :--- | :--- | :--- | :--- |
| **Index (timestamp)** | `Datetime` | UTC / PDT | 5-minute aggregation timestamps (2012-03-01 to 2012-06-27). | None (continuous 5-minute index). |
| **Columns (Sensor IDs)**| `String` / `Int` | Identifier | Caltrans PeMS detector station IDs (e.g., `773869`, `767541`). | Exactly 207 unique detector columns. |
| **Values (Speed)** | `Float32` | mph | Average traffic speed across all lanes at sensor location. | Recorded as `0.0` when sensor is down or communication fails (8.11% of readings). |

## 3. Streaming Ingestion Schema (`traffic.raw`)

JSON message format published by `kafka_producer.py` to Kafka topic `traffic.raw`:

```json
{
  "timestamp": "2012-06-10T08:30:00",
  "sensor_id": "773869",
  "current_speed": 62.45,
  "speed_lag_1": 63.10,
  "speed_lag_2": 64.50,
  "speed_lag_3": 65.00,
  "speed_mean_15m": 63.35,
  "speed_mean_1h": 61.20,
  "hour_of_day": 8,
  "day_of_week": 6,
  "is_weekend": 1
}
```

### Field Definitions:
- `timestamp` (`string`, ISO 8601): Observation timestamp representing the physical measurement window.
- `sensor_id` (`string`): Unique detector ID.
- `current_speed` (`float`, mph): Traffic speed observed at the current time interval $t$.
- `speed_lag_1` (`float`, mph): Traffic speed observed at $t-1$ (5 minutes prior).
- `speed_lag_2` (`float`, mph): Traffic speed observed at $t-2$ (10 minutes prior).
- `speed_lag_3` (`float`, mph): Traffic speed observed at $t-3$ (15 minutes prior).
- `speed_mean_15m` (`float`, mph): Backward-looking rolling average over the last 3 intervals (15 minutes).
- `speed_mean_1h` (`float`, mph): Backward-looking rolling average over the last 12 intervals (1 hour).
- `hour_of_day` (`int`, 0–23): Diurnal cycle indicator.
- `day_of_week` (`int`, 0–6): Day index where 0 is Monday and 6 is Sunday.
- `is_weekend` (`int`, 0 or 1): Binary indicator (1 for Saturday and Sunday, 0 for weekdays).

## 4. Streaming Prediction Schema (`traffic.predictions`)

JSON payload generated by Apache Spark Structured Streaming after Random Forest inference:

```json
{
  "timestamp": "2012-06-10T08:30:00",
  "sensor_id": "773869",
  "observed_speed": 62.45,
  "predicted_speed": 62.10,
  "congestion_level": "LOW",
  "prediction_timestamp": "2026-10-22T13:31:54.474524",
  "model_name": "random_forest_v1",
  "forecast_horizon_minutes": 5
}
```

### Derived Congestion Level Definitions:
- **LOW (Free Flow):** Predicted Speed $> 50.0$ mph (High-speed freeway flow).
- **MODERATE:** $35.0 < \text{Predicted Speed} \le 50.0$ mph (Slight speed decay, normal peak conditions).
- **HIGH:** $20.0 < \text{Predicted Speed} \le 35.0$ mph (Heavy congestion, stop-and-go waves).
- **SEVERE (Gridlock):** Predicted Speed $\le 20.0$ mph (Accidents, bottleneck blockages, severe delay).
